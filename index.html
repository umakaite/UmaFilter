UmaFilter

Version 1.0

Scunthorpe problem finder for Umamusume global club chat.

Due to some filter rules that check for spaces before and after filtered patterns, this checker is meant to be run on full messages, not individual words.


I don't know javascript very well, please help by contributing or reporting issues!
